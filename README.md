## Installation

For manual installation in Chrome or Microsoft Edge:

1. Download the project ZIP and extract it.
2. Open `chrome://extensions` in Chrome or `edge://extensions` in Microsoft Edge.
3. Enable **Developer mode**.
4. Select **Load unpacked** / **Paketlenmemiş öğe yükle** and choose the extracted folder's `dist` directory.
5. Open a LinkedIn Learning course and follow the extension's interface.

The extension may rely on the original project's local/native client setup for some functionality. Refer to the upstream project and its release notes for details about that component.
